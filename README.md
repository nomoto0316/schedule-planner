# Schedule Planner — 複数AIで構築スケジュールを組む（反証つき）

構築・改修プロジェクトのスケジュールを、**役割の違う複数のAIが連携して**組み上げるツールです。
過去の類似案件（実績）を根拠にタスクと日数を見積もり、**反証役のAI**が「機器の納品リードタイム」「回線工事」「予備日不足」などの穴を突いて、案を現実的に組み直します。仕上げは、人が編集ガントで手直しして確定します。

> **設計思想：AIは「案」を出し、「疑う」役と「確定」は仕組みと人が担う。**
> 生成AIで開発する現場で最も問われる「AIの出力をどう疑い、どこで人が判断するか」を、動くアプリで示すことを狙いに作りました。

---

## 何を実演できるか

| 見せたいこと | どこで示すか |
|---|---|
| **複数AIのオーケストレーション** | 実績参考→分解見積り→日程配置→**🔴反証**→統合。反証で日程を組み直す様子が画面に流れる |
| **AIを疑う設計** | AIの案はそのまま採用せず、反証役の指摘と人の確定を通す。残課題は隠さず明示 |
| **データを根拠にする** | 過去実績のリードタイムを見積りの根拠に（実績を足すほど自社の実態に寄る） |
| **秘密情報を安全に扱う** | APIキーは**サーバー側(env)だけ**。ブラウザには出さない |
| **フルスタックで作り切る** | Vue 3 SPA＋サーバーレス関数＋デプロイ。任意の入力に本物のAIが動的に応答 |

## 動かし方

### 1. 本物のAIで動かす（ログイン不要でローカル確認）
APIキーをサーバー側で保持し、ブラウザは関数経由で AI（既定は Gemini）を呼びます。**Vercelアカウント不要**。

```bash
npm install          # 初回のみ（依存の取得）
cp .env.example .env # GEMINI_API_KEY を実際のキーに書き換える（Google AI Studio の無料キー）
npm run build        # 画面をビルド
npm run start:local  # http://localhost:3001 を開く（本物AIが入力に動的応答）
```

- **無料キーの取得**：Google AI Studio（aistudio.google.com）で「Get API key」→ 発行（Googleアカウントのみ・カード不要）。
- Claude で動かしたい場合は `GEMINI_API_KEY` の代わりに `ANTHROPIC_API_KEY` を設定するだけ（コード変更不要）。
- （Vercel CLI で確認したい場合は `npx vercel dev` でも可。ただしログインが要ることがある）

### 2. 画面だけ確認する（AIなし・デモ再生）
`npm run dev` は Vite のみ。`/api` が無いので**自動でデモ再生にフォールバック**します（画面上に「デモ再生（サーバー未設定）」と表示）。

```bash
npm run dev          # http://localhost:5173
```

## デプロイ（Vercel・誰でも鍵なしで開ける）

1. このフォルダを Git リポジトリにして GitHub に push（または `npx vercel` で直接）。
2. Vercel でプロジェクトを作成（フレームワークは **Vite** が自動検出される。`api/` は自動でサーバーレス関数になる）。
3. **Project Settings → Environment Variables** に `GEMINI_API_KEY`（無料枠）を設定。※Claudeで動かすなら代わりに `ANTHROPIC_API_KEY`。
4. デプロイ。発行された公開URLを開くと、**誰でも鍵なしで・任意の案件を入れると本物のAIが動的にスケジュールを生成**します。

> env に鍵を設定しないと、公開URLでも「デモ再生」に落ちます（＝固定表示）。**本物で見せるには env の鍵設定が必須**です。
> AIの呼び先は env で自動選択（GEMINI があればGemini／無ければClaude）。**呼び出しは `api/generate.js` の1か所**に集約してあり、プロバイダの差し替えが容易です。

## アーキテクチャ

```
ブラウザ（Vue 3 SPA）
  └ LLMClient（差し替え可能な共通インターフェース）
       ├ AutoClient : サーバー優先 → 失敗時のみデモ再生へ自動切替
       ├ ServerClient : /api/generate に POST し SSE で受信
       └ DemoClient : 保存済みシナリオを再生（鍵不要・フォールバック）
          │
          ▼
/api/generate（サーバーレス関数・Node）  ← APIキー（GEMINI_API_KEY 等）はここだけ
  └ 2段の呼び出し：A=分解・見積り / B=反証・組み直し（構造化出力）
          │
          ▼
   Gemini（既定・無料枠） / Claude（envで自動選択）
```

- **AIとつながるのは1か所だけ**（`/api/generate`）。将来サーバーを厚くしても、ここを差し替えれば済む設計。
- **CPMエンジン（`src/cpm.ts`）は決定論**：工数と依存から開始/完了・余裕・クリティカルパスを計算（AIを使わず、入力が変われば必ず結果が変わる）。
- 状態は画面内のみ（サーバーに保存しない）。結果は CSV / JSON に書き出せる。

## 技術構成

Vue 3（`<script setup>` / TypeScript）・Vite・Zod（構造化出力の検証）・Google Gemini API（既定・REST／サーバー側）・Anthropic SDK（任意・切替可）・Vercel サーバーレス関数。

## 注意

- 過去実績はすべて**架空サンプル**です（実在の顧客・案件データは含めていません）。
